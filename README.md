# Tax Techie releases

Installers for **Tax Techie**, for Mac and Windows. Tax Techie fills, validates, saves, prints and submits BIR returns, as eBIRForms does.

Download it from [taxtechie.com](https://taxtechie.com/download), or from the [releases](https://github.com/unisoftventures/taxtechie-releases/releases) here. Each release lists its files' SHA-256 so you can check what you downloaded.

This repository holds only the installers; Tax Techie's source isn't here.

Tax Techie is not affiliated with or endorsed by the Bureau of Internal Revenue.
